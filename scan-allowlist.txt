# scripts/scan.sh fails the build on any host not listed here, so a new
# outbound endpoint in an upstream release stops the rebuild for review.

# A host listed here is NOT necessarily contacted at runtime. Each entry
# says why it is in the binary. Reviewed 2026-10-11 and 2026-10-24 against the sources.

# per-app allowances.

# "Download Place Names (GeoNames)" for offline reverse geocoding (0.13.0,

# the web build shows the attribution string but cannot fetch the data.
download.geonames.org

[filmcraft]
